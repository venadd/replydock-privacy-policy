ReplyDock — Privacy Policy

Publisher: Venadds • Application: ReplyDock for Windows • Effective Date: November 2026
100% Offline • Zero Telemetry • Local-First

1. Overview and Core Privacy Commitment

At Venadds, we believe that your clipboard contents and personal productivity data belong strictly to you. ReplyDock is engineered from the ground up as a 100% offline, local-first desktop utility for Windows 10 and Windows 11.

Core Guarantee: ReplyDock makes zero outbound network connections, includes zero tracking or telemetry beacons, requires no user registration, and stores all data exclusively on your local device.

2. What Information ReplyDock Handles

Because ReplyDock operates as a desktop clipboard manager and canned response template dock, it processes the following information locally on your computer:

  • Clipboard History: When active, ReplyDock monitors your Windows clipboard to record copied plain text snippets so you can access, search, and reuse them later.
  • Templates and Categories: Reusable text templates, custom categories, and dynamic variable definitions (such as {{name}}) created by you.
  • Application Preferences: Local configuration options including interface theme (Dark or Light), custom global keyboard shortcuts, and history retention thresholds.

None of this data is ever transmitted over the internet. Venadds has no access to your clipboard text, your templates, or your device information.

3. Local Storage and Data Security

All application state is stored locally on your machine in an offline SQLite database:

  • Default Database Location: %APPDATA%\com.replydock.desktop\replydock.db
  • Access Isolation: Database access is restricted to the ReplyDock local application process within your Windows user account boundary.
  • Integrity: All internal queries use parameterized SQL bindings to guarantee database reliability.

4. User Control and Data Erasure

You have full and continuous control over all information captured by ReplyDock:

  • Pause Monitoring: You can temporarily suspend clipboard monitoring at any time by right-clicking the ReplyDock system tray icon and selecting "Pause Monitoring", or via the toggle in Settings.
  • Delete Specific Items: Any individual clipboard entry or template can be deleted permanently with a single click.
  • Clear All History: You can purge your entire clipboard history at any time from the Settings panel.
  • Automatic Retention Limits: Configure maximum item limits (e.g., retaining the last 50, 100, or 200 items). Starred (Favorite) items are protected from automatic retention pruning.
  • Clean Uninstallation: Uninstalling ReplyDock through Windows Settings removes the application binary and its local application state completely.

5. Third-Party Services and Telemetry

ReplyDock contains zero third-party SDKs, zero advertising networks, zero cloud analytics, and zero automated crash reporting telemetry. The application functions entirely offline.

6. Children's Privacy

ReplyDock does not collect personal data from anyone, including children under 13 years of age. It is completely safe and appropriate for all audiences.
